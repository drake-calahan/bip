# Bip — agent toolbox (v2 branch)

Working conventions for any agent (human or AI) contributing to Bip v2.

## Project facts

- Kid coding game (French, ~6 yo / CP-CE1). PWA, single-file build (`index.html`) generated by `python tools/build.py`.
- Sources: `src/engine.js` (pure sim, Node-testable), `src/levels.js` (content), `src/body.html` (HTML+CSS+SVG defs), `src/app-*.js` (UI, concatenated in one IIFE by build).
- **Tone is the product**: soft pastel, no timers, no lives, no villains, gentle failures ("oups"), voice reads everything (fr-FR TTS), tutoiement, short sentences. Never add pressure mechanics.
- Every level must be validated: `node tools/check-levels.js` → must print `ALL OK`.
- After any src change: `python tools/build.py`, bump `VERSION` in `sw.js` when shipping.

## Hard rules

1. Engine (`src/engine.js`) stays pure: no DOM, no `window`. It must `require()` cleanly in Node (checker depends on it).
2. All in-game copy in French, warm, ≤ 2 short sentences per bubble. Design docs may be English.
3. One new idea per level. A new mechanic always debuts in a near-trivial showcase level with an explaining voice line.
4. Battery limit (`max`) only to force the chapter's concept, never to frustrate (ref solution must fit with ≥1 spare block when possible).
5. Solvability: simple levels rely on the BFS solver; any level using crates/gates/switches/ball mode must provide an explicit `sol` (program string) or `tiles` (ball ref) — the checker verifies it wins on every variant.
6. Stars: 3 = blocks ≤ par, 2 = ≤ par+2, else 1. Par = ref length. Never punish: 1 star is always a full success.

## Level DSL quick reference (`src/levels.js`)

Map legend: `.` grass · `#` bush · `o` rock · `~` puddle · `K` chest · `R` robot start · `-` lily pad · `s` switch (mushroom) · `G` gate (closed) · `C` crate · `*` flower (paint target) · `S` ball start · `N` nest (ball goal) · toys `b n c t a e` (e = firefly).
Program mini-lang (`sol`, `start`, `fn`): `r l u d` arrows · `f tl tr` relative · `j` jump · `N3(...)` repeat ×3 · `Wo(...)` until obstacle · `Wt(...)` until all toys · `Ip(a|b)`/`Io(a|b)` if puddle/obstacle · `*` magic block.
Fields: `ch` chapter idx · `pal` palette · `map`/`variants` · `face` start facing · `max` battery · `sol`/`fn` reference solution · `start`/`startFn` detective pre-program · `mode:'ball'` + `tiles` ref · `daily:true`.

## Definition of done (per content batch)

- `node tools/check-levels.js` → `ALL OK` (every level: ref wins in all variants, detective starts fail, par ≤ max, difficulty curve printed sane).
- `python tools/build.py` then manual smoke in browser: home → play 1 level of each mode (classic, pond, paint, crate, ball) → win → sticker toast.
